# 导航路线图设置规则

## 适用范围

- 需要理解路线图节点、边、权重、避让节点、库位前路径结构等 CBS 路线规则。
- 用户描述偏向“为什么会车混乱”“为什么这里总绕圈”“库位前为什么总卡住”“路线图怎么画才对”。

## 历史复盘优先

- 这页主要提供路线图设计和规则约束，不直接等于某次历史导航故障的根因。
- 如果是“某次导航 / 会车 / 库位作业失败”，应先回看当时的路线图、任务时间线和避让行为，再判断是不是路线图设计问题。
- 不要只因为当前路线图已经改过，就反推历史那次故障一定不是图设计引起的。

## 常见检索词

- 路线图怎么画
- 节点间距
- 会车冲突
- 绕圈
- 避让节点
- 充电桩路径点
- 库位前不能画环
- 路线权重
- 动态擦除节点

## 基本约束

- R1、R2、R3 取最大值 = **最大旋转半径**，取最小值 = **最小旋转半径**
- 路线点间距推荐 > **最大旋转半径×2 + 10cm**，最短 ≥ 最大旋转半径 + 最小旋转半径 + 10cm
- 路线点离障碍物（含虚拟墙、目标货物）推荐 > **最大旋转半径 + 10cm**，最短 ≥ 最小旋转半径 + 10cm
- 点离墙 > 50cm
- 点间距建议 3m 左右（可按车身长度灵活调整）

## 节点类型

| 类型 | 说明 |
|------|------|
| 普通节点 | 默认，无特殊行为 |
| 高优先级避让节点 | 引导机器人避让时远离主干道，偏移到旁路节点 |
| 动态擦除节点 | 货物堆积导致不通时，临时移除并重规划（有安全兜底验证） |

## 节点属性

### 跨节点跳变阈值
增强"粘性"，抑制抖动。只有偏离当前节点距离超过阈值才切换。避免微小位置波动引发不必要重规划。

### 停靠朝向
约束避让等待时车身姿态。狭窄通道中确保车身沿通道方向贴边停放。

## 边的设置

- 默认双向连接（可往返行走）
- 单向连接用于特定方向限制
- **权重**：避让距离，默认1m，可设10m使机器人寻找更远的避让点

## 多机调度规则

- 路线相交于某点时，除第一台外的机器人会前往该点附近点避让
- 避让机器离开交汇点后，等待机器才能通过

## 重要注意事项

### 库位前路线不能画环形
库位前方必须为**分支状**结构（非环形），避免多机调度混乱。

### 充电桩/休息区需独立路径点
每个充电桩/休息区需单独对应专属路径点；共用路径点会导致同时仅一台能进入。

### 并排库位路径点设置
- 需同时作业 → 每个库位前独立路径点
- 库位过密无法同时取放 → 路径点稀疏设置（多个库位共享一个路径点，区域内仅允许单台作业）

### 保存即时生效
保存后配置立即生效，自动同步所有机器人路线（包括正在执行任务的）。
**执行任务期间保存路线图会触发重规划，可能报错/路线混乱。尽量在机器人空闲时编辑。**

## 作业空间要求

动作空间宽度 = √(a² + b²) + 0.25m
- a = 车长, b = 托盘宽度
- 标准车(1.75m) + 标准托盘(0.8m) → 需 2.15m

库位间距：左右20cm, 前后5cm

## 托盘要求

- 必须为**川字型**托盘（被叉方向无下方加固条）
- 建议尺寸：120cm × 80cm
- 插孔高度 > 10.5cm

## 推荐排查顺序

1. 先判断问题更像图设计问题，还是定位 / 底层 / 动作执行问题。
2. 如果是历史问题，先固定失败时间和当时任务路线。
3. 再看节点间距、边方向、避让点、库位前结构和充电位路径点设计。
4. 如果只是某一类任务失败，再联查托盘、场景几何和动作空间约束。
