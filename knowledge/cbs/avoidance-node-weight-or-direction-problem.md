# 避让节点权重或方向设置不合理

## 适用范围
- 多机调度中，避让节点虽然存在，但机器人让路效果不好、绕行异常或方向限制导致规划不合理。
- 适用于“有避让点但还是卡”“绕太远或不愿意去避让点”的问题。

## 历史复盘优先

- CBS / 路线问题通常要结合当时任务、路线图和会车场景回看，不要只看当前地图配置。
- 如果现场已经改过路径、节点或权重，当前配置不能直接代表历史故障时的真实状态。
- 应优先固定故障时间、任务路线和对应图设计，再判断是否属于规则或图结构问题。

## 典型现象
- 机器人不去预期避让点，或总选出奇怪路线。
- 避让后仍堵住主通道，没有真正让出空间。
- 某些单向边或权重设置后，局部规划明显异常。
- 同一区域会车冲突频繁，但图上看似已经有避让节点。

## 优先检查
1. 先确认冲突区域是否已有专用避让节点。
2. 检查该节点权重、边方向、停靠朝向是否合理。
3. 确认避让节点是否真的离主干道足够远。
4. 再判断问题是“避让点不存在”还是“避让点存在但配置不合理”。

## 关键日志
- 路线图配置页面
- CBS / 调度中心日志
- 问题区域相关路径规划记录

## 常见检索词
- 避让点不合理
- 权重不对
- 单向边问题
- 不去避让点
- 绕行异常
- 让路没让开

## 判定口径
- 如果避让点存在但效果差，更像权重、方向或停靠设置问题。
- 如果根本没有合适避让点，更像路线图结构设计不足。

## 常见根因
- 避让节点权重过低或过高。
- 边方向设置与现场通行方向不匹配。
- 避让节点离主干道太近，无法真正让开。
- 停靠朝向不合理，导致让路后姿态仍冲突。

## 处理建议
1. 先在冲突区域核对避让节点位置和方向。
2. 如果机器人总选错避让点，优先调权重和边方向。
3. 如果避让后仍挡路，优先调整节点位置和停靠朝向。
4. 调整后安排多机交会复测，确认让路效果稳定。
