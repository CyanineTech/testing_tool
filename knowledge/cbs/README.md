# CBS 与路线规则入口

本目录用于承接 CBS 路径规划、路线图规则、节点设计和调度相关导航约束问题。

## 适用范围

- 路径规划异常、路线不通、节点设置不合理、多机调度互锁问题。
- 用户描述偏向“路线不走”“规划失败”“地图规则不对”“节点设置有问题”。

## 常见检索词

- 路线不走
- 规划失败
- 路线不通
- 节点设置有问题
- 地图规则不对
- 会车冲突
- 多机互锁
- cbs 规划异常
- 导航点建模问题
- 库位规则异常

## 建议优先补充的子类页

1. 节点类型与间距设计
2. 多机调度互锁 / 会车问题
3. 路线规则与通行方向
4. 库位与导航点建模问题
