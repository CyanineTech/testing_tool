# 麦轮机型硬件差异与排障注意点

## 适用范围
- 适用于 `mecanum`、`mecanum_small` 等麦克纳姆轮机型的排障。
- 用于区分“通用 AMR 问题”和“麦轮底盘 / 运动控制特有问题”。

## 典型现象
- 机器人可动，但姿态、横移、转向表现与叉车 / 舵轮机型明显不同。
- 同样的路线或点位，在麦轮机型上更容易出现横移偏差、贴边不稳或避障空间不足。
- 底层状态正常，但现场表现像“控制不顺”“横移不自然”“路径抖动”。

## 优先检查
1. 先确认当前问题是否与横移、姿态控制、狭窄通道或贴边行走有关。
2. 检查 `/odom`、`/cmd_vel`、底盘控制相关 topic 是否连续稳定。
3. 对照机型参数、轮组状态和地面条件，判断是否属于麦轮特有运动学表现。
4. 再判断是底层控制、导航局部规划，还是现场地面 / 负载导致的放大问题。

## 关键日志
- `/odom`
- `/cmd_vel`
- `default.launch`
- `mobile_base.launch`
- 机型配置和底盘参数

## 常见检索词
- 麦轮机型
- mecanum
- 横移异常
- 姿态不稳
- 贴边不稳
- 小范围抖动

## 判定口径
- 如果问题主要发生在横移、侧向调整、狭窄空间贴边，更像麦轮机型差异问题。
- 如果与底盘形式无关，更优先按通用导航或硬件故障排查。

## 常见根因
- 麦轮机型对地面附着、轮组状态和局部规划参数更敏感。
- 横移与姿态控制在狭窄空间更容易放大误差。
- 机型参数、轮径或底盘控制设置与现场状态不完全匹配。

## 处理建议
1. 先确认是否属于麦轮机型特有表现，不要直接套叉车或舵轮经验。
2. 优先结合机型参数、局部规划和地面条件综合判断。
3. 修复后在横移、转向、贴边三个典型动作上分别复测。
