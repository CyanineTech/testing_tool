# 服务超时或不通

## 适用范围
- RCS 后端接口超时。
- 调度中心、任务执行、数据库或网关服务响应慢。
- 用户常见描述包括“服务不通”“接口超时”“请求卡住”“服务挂了”。

## 典型现象
- 飞书或前端操作后无返回。
- 任务下发后长时间没有状态变化。
- 后端日志出现超时、拒绝连接或反复重试。

## 优先检查
1. 先确认目标服务实例是否还在运行。
2. 再看端口、容器、数据库和任务链路是否正常。
3. 如果只有某个接口慢，再看对应日志和请求时间点。

## 关键日志
- RCS 主机上的后端日志、调度中心日志、任务系统日志
- Docker 容器日志和端口状态
- 若是联动问题，再看消息链路和数据库状态

## 常见根因
- 服务进程异常退出或反复重启。
- 依赖服务不可用，导致请求堆积。
- 资源不足、线程阻塞或数据库响应慢。

## 处理建议
1. 先确认是单服务问题还是链路问题。
2. 再按端口、容器、日志顺序逐层排查。
3. 如果影响任务执行，优先恢复主链路，再追根因。
