# 充电任务专项

## 适用范围
- 适用于自动充电、回充、退出充电、充满后释放等任务链路问题。
- 用于把“充电失败”从普通任务问题中拆出来，单独看任务流、状态位和电极链路。

## 典型现象
- 机器人能到充电位，但无法真正进入充电状态。
- 显示在充电任务中，但电流、电极或状态位不符合预期。
- 充满后不退出、不释放，或退出后任务状态不推进。
- 同一充电位重复失败，而其他充电位正常。

## 优先检查
1. 先确认问题是“到不了充电位”还是“到了但充不上 / 退不出”。
2. 检查 `/motor_control/low_level_status`、充电调试 topic、电极状态和电流变化。
3. 检查任务系统中自动充电相关事件、状态推进和释放逻辑。
4. 再结合现场充电桩、对位精度和主从后端状态判断断点。

## 关键日志
- 充电任务日志
- `/motor_control/battery_debug.*`
- `/motor_control/motor_control_debug.*`
- `default.launch`
- `mobile_base.launch`

## 常见检索词
- 充电任务失败
- 到桩不充电
- 充满不退出
- 充电状态卡住
- 电极没打开
- 回充任务异常

## 判定口径
- 如果机器人到不了充电位，更像导航、点位或现场几何问题。
- 如果到位但电流、电极状态不对，更像充电链路或状态机专项问题。

## 常见根因
- 充电对位不准。
- 电极、状态位或电流判断异常。
- 自动充电任务状态机未完整推进。
- 充电桩现场状态或通信异常。

## 处理建议
1. 先区分“到位失败”和“充电链路失败”。
2. 如果是链路问题，优先查电极状态、电流变化和任务推进逻辑。
3. 如果只在单个充电位失败，优先查该点位和充电桩现场。
4. 修复后完整复测“进桩 - 充电 - 退出 - 释放”全链路。
