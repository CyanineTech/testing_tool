# 麦轮机型 + 狭窄通道任务专项

## 适用范围
- 适用于 `mecanum`、`mecanum_small` 机型在狭窄通道、贴边、会车和精细进出任务中的专项问题。
- 用于把“麦轮运动学表现”和“狭窄空间任务”组合起来判断。

## 历史复盘优先

- 任务问题优先围绕任务创建、卡住、恢复和人工干预的时间线复盘。
- 不要只因为任务最终完成或当前机器人在线，就忽略最初卡住时的真实断点。
- 应优先回看主机任务流、从机动作、事件回执和现场条件变化。

## 典型现象
- 机器人在狭窄通道中容易抖动、贴边不稳或绕行奇怪。
- 同一路线在宽阔区域正常，进窄通道后成功率明显下降。
- 多机、避让、贴边和横移动作叠加后问题更明显。

## 优先检查
1. 先确认问题是否集中在狭窄通道、贴边、让路或精细进出区域。
2. 检查路线图节点间距、障碍物距离、避让点和局部规划表现。
3. 对照麦轮机型差异页，判断是否为横移 / 姿态控制边界被放大。
4. 再判断是路线图问题、局部规划问题还是机型运动学边界问题。

## 关键日志
- `/odom`
- `/cmd_vel`
- 路线图配置
- 相关任务日志与 bag

## 常见检索词
- 麦轮窄通道失败
- 麦轮贴边不稳
- 会车区抖动
- 横移调整异常
- 狭窄区域绕行怪

## 判定口径
- 如果宽路正常、窄路异常，更像窄通道专项问题。
- 如果全场都异常，更像底盘、传感器或定位本身问题。

## 常见根因
- 麦轮横移与姿态控制在狭窄区域鲁棒性不足。
- 路线图留边、间距或避让设计对麦轮不友好。
- 局部规划与现场实际通行空间不匹配。

## 处理建议
1. 先把问题限定到特定通道和任务类型。
2. 优先联合看机型差异、路线图和局部规划。
3. 修复后在单机、会车和贴边三种窄通道任务上复测。
