# 现场无线干扰 / 金属遮挡专项

## 适用范围
- 适用于现场存在大量金属货架、电梯井、封闭通道、变频器、电机柜等区域，机器人在特定位置网络显著变差的场景。
- 用于区分“普遍网络差”与“现场局部环境导致的无线干扰 / 遮挡问题”。

## 典型现象
- 机器人在固定区域反复掉线，离开该区域后恢复。
- 同一条路线总在某段通道、电梯口、货架间掉线。
- RSSI、延迟、丢包在局部区域明显恶化。
- 多台机器人经过同一区域时都更容易复现。

## 优先检查
1. 先确认问题是否与固定物理区域强相关。
2. 记录掉线位置、路线方向和现场障碍物布局。
3. 检查 WiFi 信号强度、AP 布局和 1300D 接入方式。
4. 再判断是金属遮挡、反射、多径干扰还是电磁环境造成的链路抖动。

## 关键日志
- `nmcli d show`
- `ping`
- `tailscale status`
- 现场 AP 覆盖图或信号测试记录
- 同一路线不同时间段的掉线时间点

## 常见检索词
- 某个区域掉线
- 电梯口掉线
- 货架间信号差
- 金属遮挡
- 无线干扰
- 局部网络死角

## 判定口径
- 如果仅在固定现场区域复现，更像无线环境或遮挡专项问题。
- 如果全场景都不稳定，更像基础网络、路由器或主机链路问题。

## 常见根因
- 金属货架、封闭空间造成 WiFi 覆盖衰减。
- 电机柜、变频器、充电设备等带来电磁干扰。
- AP 部署位置不合理，漫游区和盲区重叠。
- 1300D 放置位置、天线角度或入网方式不适合现场。

## 处理建议
1. 优先按“现场区域问题”建档，不要只看单台机器人。
2. 结合多台机器人和多次路线复测，确认问题区域边界。
3. 优先优化 AP、路由器摆位和局部补盲，再决定是否换接入方式。
4. 修复后要复测同一段路线，而不是只在静止点位测网络。
